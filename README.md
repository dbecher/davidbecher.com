# WordPress Site Template 1 - no tooling

A template site for GitHub deployments.

## Contents

With this template you can easily develop your WordPress site and connect it with our [WordPress.com GitHub versioning system](https://wordpress.com/support/deploy-from-github-workflow).

## Installation

- Clone this respository and create a site on WordPress.com 
- Connect your GitHub with WordPress.com [following these steps](https://wordpress.com/support/deploy-from-github-workflow)
- Start developing and notice that each change will reflect in realtime on our servers
